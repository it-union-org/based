# samples — тестовые данные

Все данные в этой папке **синтетические**. Они созданы специально для проверки
основного пользовательского сценария и не содержат персональных данных.

## Состав

| Файл | Назначение | Формат |
|---|---|---|
| `schedule_sample.csv` | Расписание для загрузки через бота | CSV с заголовками |
| `tasks_sample.txt` | Три домашних задания | Строки `предмет \| дата \| описание` |
| `note_sample.md` | Пример конспекта | Markdown с формулами и Mermaid |
| `output/` | Результаты проверки | Создаётся автоматически |

## Ожидаемый результат по каждому файлу

| Файл | Что должно произойти |
|---|---|
| `schedule_sample.csv` | Бот сохранит 3 занятия и покажет пары на ближайшую дату |
| `tasks_sample.txt` | Бот добавит 3 задачи, покажет их в списке активных |
| `note_sample.md` | Сконвертируется в PDF с формулами, диаграммой и заголовками |

## Сценарий проверки

### 1. Расписание

**Через бота:**

1. «Расписание → Загрузить файл».
2. Отправить `samples/schedule_sample.csv`.
3. Ожидаемое сообщение: «Расписание сохранено: 3 занятий, 2026-09-29–2026-09-30».
4. Нажать «Сегодня» — бот покажет пары с временем, предметом, преподавателем и аудиторией.

**Через Python:**

```bash
python -c "import asyncio; from pathlib import Path; from based.modules.skeds.api import SkedsAPI; s = asyncio.run(SkedsAPI().parse(Path('samples/schedule_sample.csv'), group_name='__demo__')); print(f'lessons={len(s.lessons)} from={s.from_date} to={s.to_date}')"
